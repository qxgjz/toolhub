# ToolHub - Free Online Tools Collection

> 49+ free online tools, all running locally in your browser. No registration, no data upload, open and use.

## Live Demo

**Website**: https://www.toolhub.asia

## Overview

ToolHub is a pure-frontend online tools website. All calculations and processing happen client-side in the user's browser -- no backend server, no database, no data collection. Every tool is accessible via a dedicated URL and supports dark mode, responsive design, and PWA installation.

## Quick Start

### Option 1: Use Online

Visit https://www.toolhub.asia

### Option 2: Deploy Your Own

```bash
# Clone the repo
git clone https://github.com/qxgjz/toolhub.git
cd toolhub

# Serve locally (any static server works)
npx serve .
# or
python -m http.server 8080
```

### Option 3: Deploy to GitHub Pages

1. Fork this repository
2. Go to Settings -> Pages
3. Source: main branch, /root directory
4. Your site will be live at `https://yourusername.github.io/toolhub/`

### Option 4: Deploy to Cloudflare Pages

1. Connect your GitHub repository
2. Framework preset: "None"
3. Deploy
